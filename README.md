# 🏆 Betking DX | AI Спортивная Аналитика и Автоматизация

**Betking DX** — это высокотехнологичная платформа на базе искусственного интеллекта (Genkit/Gemini), разработанная для глубокого анализа спортивных событий и полной автоматизации SMM-процессов в Telegram.

## 🌟 Ключевые возможности

### 🤖 ИИ-Аналитика и Live-Сканер
- **Live Автоматизация 4.0**: Автоматический парсинг линии и поиск валуйных ставок.
- **Инсайды из Telegram**: ИИ анализирует более 50 верифицированных источников.
- **Wait-Strategy Algorithm**: Прогноз оптимального времени для ставки (рост коэффициента).

### 📢 Telegram Автоматизация (SMM)
- **Автопостинг 24/7**: Полностью автономная публикация через GitHub Actions.
- **AI Image Generation**: Уникальные изображения от **Imagen 4** для каждого поста.
- **VIP Экспрессы (x5+)**: Ежедневная генерация "бетонных" экспрессов.

## 🔐 Настройка секретов (Security & Secrets) — ПОДРОБНАЯ ИНСТРУКЦИЯ

Чтобы автоматизация заработала, вам нужно настроить "секретный пароль" (CRON_SECRET) в двух местах. Это нужно, чтобы только ваш GitHub мог управлять вашим ботом.

### Шаг 1: Настройка в GitHub (Отправитель)
1. Откройте ваш репозиторий на **GitHub**.
2. Перейдите во вкладку **Settings** (Настройки) в верхнем меню.
3. В левом столбце найдите раздел **Secrets and variables** и нажмите на **Actions**.
4. Нажмите зеленую кнопку **New repository secret**.
5. Добавьте первый секрет:
   - **Name:** `APP_URL`
   - **Value:** Ссылка на ваш готовый сайт (например: `https://vash-sait.web.app`)
6. Нажмите **Add secret**.
7. Нажмите еще раз **New repository secret** и добавьте второй:
   - **Name:** `CRON_SECRET`
   - **Value:** Придумайте любой сложный пароль (например: `MySuperPass123`)
8. Нажмите **Add secret**.

### Шаг 2: Настройка на Хостинге (Vercel / Firebase / Другой)
Теперь ваш сайт должен узнать этот же пароль. Зайдите в панель управления вашим сайтом в раздел **Environment Variables** (Переменные окружения) и добавьте:
1. **CRON_SECRET**: Вставьте тот же самый пароль (`MySuperPass123`).
2. **TELEGRAM_BOT_TOKEN**: Вставьте ваш токен `8622605577:AAGcDrJxrzJ_uR-kzuv7iUz2IJo6qwC3Pfo`.
3. **GOOGLE_GENAI_API_KEY**: Вставьте ваш API ключ Google Gemini.

## 🛠 Как запустить вручную
Если вы не хотите ждать расписания, вы можете запустить пост прямо сейчас:
1. В GitHub перейдите во вкладку **Actions**.
2. Слева выберите **Betking DX Auto Posting**.
3. Нажмите **Run workflow** -> **Run workflow**.
